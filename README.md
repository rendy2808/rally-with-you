# Rally — Couple Match Tracker 🎾

Skor pertandingan lo vs pasangan. PWA offline-first, mobile-first.

## Stack
- Vue 3 + Vite + Pinia
- IndexedDB (Dexie) — data lokal, offline-first
- PWA (vite-plugin-pwa) — installable
- Tailwind CSS v4

## Dev
```bash
npm install
npm run dev
```

## Build & Deploy
Auto-deploy ke GitHub Pages via Actions (push ke `main`).

Live: https://rendy2808.github.io/rally-with-you/
